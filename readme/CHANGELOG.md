## [1.00.018] - 2026-09-18

### 🚀 音源调度与网络波动自愈
- **Tier 1 外层超时放宽至 10 秒**：
  - 自定义音源外层超时由 7500ms 扩大至 10000ms，为公网网络抖动留出充足缓冲，彻底避免沙箱脚本解析被外层过早掐断。
- **解析接口网络波动智能重试**：
  - 原生解析接口遇到网络超时或连接重置时，支持自动重试 1 次，大幅提升公网弱网环境下的出链成功率。
- **原生 API 与沙箱脚本智能竞速调度 (Race Scheduling)**：
  - 网易云平台启动原生极速通道与 WebView 沙箱并发竞速；
  - 两者同时发起解析，先成功出链者直接起播，出链即用，消除串行死等耗时。

### 🐞 循环播放自动暂停根治与无感本地化
- **单曲循环本地缓存平滑热迁移 (Local Cache Seamless Handover)**：
  - 单曲循环（`repeat-one`）每轮播完触发时，自动检测本地缓存文件是否已落盘；
  - 一旦就绪，立即热切换为本地文件（`file:///...`）无缝循环播放；
  - 彻底摆脱远程直链 20~30 分钟防盗链时效限制，息屏或离线断网无限循环绝不中断。
- **解除原生 OkHttp 6 秒下载限制**：
  - 移除下载模块中的 `callTimeout(6s)` 限制，改用科学的流读取超时，确保 10MB~20MB 高清音频文件 100% 完整落盘。
- **流健康看门狗 (Stream Stalled Watchdog)**：
  - 离线未就绪情况下若远程流持续缓冲超过 8 秒未出声，看门狗自动触发重新解析最新直链并在原地恢复播放。

### 📱 系统通知栏与播放交互修复
- **通知栏进度条拖拽全面恢复**：
  - 原生 `MediaService` 补齐 `PlaybackStateCompat.ACTION_SEEK_TO` 声明；
  - `MediaSessionCompat.Callback` 实现 `onSeekTo` 回调并打通至播放引擎，系统通知栏和锁屏进度条拖拽恢复正常响应。
- **解除缓冲假死与播放短路**：
  - 缓冲超过 4 秒未出声如实反映非播放状态，UI 播放按钮变回播放图标；
  - 修复通知栏点击播放被 JS 端 `if (!isPlaying)` 短路拦截的问题，底层未发声时强制唤醒播放。

## [1.00.017] - 2026-09-17

### 🚀 性能飞跃与极速缓存体系 (100% 命中)
- **本地文件缓存直接起播（100倍提速）**：
  - 修复此前本地已命中完整音频缓存时仍发起漫长网络级联请求并等待沙箱的严重缺陷；
  - 命中本地缓存文件时跳过一切网络请求与多梯队解析，起播耗时由 5.5 秒骤降至 50~100 毫秒；
  - 增设本地损坏文件自动熔断与网络重试拉取机制。
- **根除缓存文件路径多重拼接缺陷（杜绝误删缓存）**：
  - 彻底修复 `file:///file:///...` 导致原生 ExoPlayer 报 `FileNotFoundException` 并错误将完整缓存当成坏文件删除的致命死循环；
  - 新增全局 `normalizeAudioUri`，杜绝任何路径异常，保障已缓存歌曲 100% 秒开。
- **内存级缓存快速索引树 (0ms 判定)**：
  - 引入 `Set<string>` 内存缓存索引树，切歌判定文件存在耗时降至 0 毫秒，免除底层 JNI 和磁盘 Stat 耗时。
- **多音源候选 ID 模糊匹配**：
  - 统一全平台别名，支持酷狗 `HASH|audio_id` 与纯 `HASH` 双向匹配，防止因格式差异错失本地缓存。
- **下一曲智能静默预载引擎 (Gapless Next-Song Preloading)**：
  - 当前曲目起播稳定 6 秒后，后台线程自动静默预先解析并缓存下一首歌曲，切歌或自然播完时 100% 闪电起播。
- **消灭前台网易云 3.5 秒等待**：
  - 解除原生极速直链 API 仅在后台生效的限制；
  - 网易云在前台播放时同样优先直走原生极速通道，600~900ms 极速出链，彻底消除沙箱 3500ms 超时白等。

### 🐞 核心缺陷修复
- **根治后台单曲循环开头音乐重复播放两次**：
  - 排查并修复 `repeat-one` 模式下底层 ExoPlayer 原生 `isLooping` 无缝循环与 JS 层 `didJustFinish` 回调再次调用 `replayAsync()` 冲突的竞态；
  - 单曲循环完全由原生播放器无缝连续循环，彻底消除开头 200~400ms 重音复播现象。
- **原子化临时文件下载机制**：
  - 下载器改用 `.tmp` 临时文件机制，校验完整且字节大于 1KB 后再原子重命名为 `.mp3`，彻底避免半截坏文件进入缓存。

### 📡 实时诊断与日志系统升级
- **AI 实时调阅原生 HTTP 诊断服务**：
  - Android 原生层集成超轻量 HTTP 诊断服务（监听端口 `18088`，空闲时 0% CPU 占用）；
  - 提供 `/logs`（实时调阅内存环形日志）、`/cache`（调阅本地音频缓存清单）、`/logs/today`（调阅全量落盘文件）、`/status`（播放引擎状态 JSON）、`/ping` 等接口；
  - 配合一键脚本 `scripts/get_realtime_logs.ps1`，支持 AI 与开发者通过 ADB 转发或局域网实时毫秒级查看真机日志与缓存状态。
- **Android Logcat 双轨透明输出**：
  - 日志自动同步转发至系统 Logcat (`NeonLogger` 标签)，支持 `adb logcat -s NeonLogger` 即时抓取。
- **日志细节全面丰富化**：
  - 内存环形缓冲区容量由 200 行扩容至 1000 行，详细记录播放生命周期关键耗时、缓存命中、音源排除原因与网络状态。

## [1.00.016] - 2026-09-16

### 🚀 核心优化与重构
- **根治后台播放卡顿与中断**：
  - 消除 `MediaService` 中 100ms 高频进度更新所引发的系统 Binder IPC 通信阻塞；
  - 进度显示改由系统 `PlaybackStateCompat` 原生插值机制推算，极大降低系统负载；
  - 媒体会话（MediaSession）状态同步调整为 1 秒防抖，保证锁屏与控制中心流畅响应。
- **全应用高频渲染性能解耦**：
  - 从全局状态库抽离独立的 `usePlaybackProgress` Hook，解耦全屏播放器及各个页面的高频进度重渲染；
  - 播放器处于收起或后台状态时，相关 UI 组件实现零额外重渲染。

### ✨ 新增功能
- **跨源故障转移与设置开关**：
  - 在【设置】->【播放设置】中新增【跨源故障转移】功能开关；
  - **开启（默认）**：当前音源失效或无版权时，自动在其他平台检索同名歌曲并使用可用音源无缝播放；
  - **关闭**：严格遵循用户选定音源，若不可播放则直接提示失败，绝不擅自换源。

### 🛡️ 音源调度与安全加固
- **同名匹配防偷换机制**：跨平台同名匹配引入严格的负向特征词过滤（剔除伴奏、Remix、片段、现场版等），并校验歌曲时长误差（超过 25 秒自动剔除）；
- **缓存防投毒保护**：发生跨源降级或故障转移的曲目严禁写入长期 URL 缓存，杜绝伴奏/翻唱等错误直链被持久化固化；
- **音源参数兼容性补齐**：修复酷狗曲目搜索与 ID 中的 `albumId` 专辑参数提取并完整传递至沙箱；
- **稳定性安全阀**：歌词解析增设 2.5 秒超时保护；设置页检查更新增加状态锁与连击防抖。
